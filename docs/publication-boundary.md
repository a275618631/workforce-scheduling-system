# Publication Boundary

## What this repository contains

- Architecture documentation
- Engineering decision rationale
- Constraint model description
- Validation approach and test count
- Synthetic example data references (no actual data files)

## What this repository does not contain

- Private source code
- Real personnel records, names, or identifiers
- Real duty rosters, shift assignments, or scheduling outputs
- Non-public organizational policies or operational rules
- Unit-specific configurations tied to real organizations
- Any credentials, access material, or account information

## Why

The system was originally developed for a rotating-shift public-sector environment. The scheduling constraints, personnel data, and operational context are specific to that environment and are not appropriate for public disclosure.

The architecture, engineering decisions, and validation approach are general enough to describe without referencing any real-world operational detail.

## Data

All personnel records used in development are synthetic: anonymized identifiers, generated names, and fabricated attributes. No real personnel records, real unit configurations, or real operational data were used or are present in this repository.

## Private implementation

The source code repository is private. This companion does not attempt to reproduce or summarize the implementation beyond what is described in the architecture documentation.
